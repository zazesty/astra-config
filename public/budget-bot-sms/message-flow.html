End-to-end opt-in flow (every path)

1A

Path A — Keyword request

Subscriber texts one of these keywords to the Budget Bot long code:

BUDGET

or

START
1B

Path B — Program invitation

Budget Bot may send a one-time welcome invitation to a mobile number the program owner intends to enroll (for example the sole proprietor’s own phone). This is not silent enrollment; the recipient must still complete Step 2.

2

Welcome / Call-to-Action (Budget Bot → subscriber)

Same welcome for Path A and Path B. Includes brand identity, purpose, frequency, “message and data rates may apply,” HELP/STOP, Privacy + Terms links, and an explicit YES request.

Budget Bot: Hi — this is Budget Bot (operated by Zavdi). You are being offered personal budget alert texts: hardcap warnings, hardcap breaches, and pace warnings only (not marketing). Msg frequency varies (typically fewer than 10/mo). Msg & data rates may apply. Reply YES to agree and enroll. Reply STOP to cancel, HELP for help. Privacy: https://zaz-astra.tail5d74e1.ts.net/budget-bot/privacy.html Terms: https://zaz-astra.tail5d74e1.ts.net/budget-bot/terms.html
3

Active consent (subscriber → Budget Bot)

Clear opt-in keyword the customer texts (not pre-checked; affirmative action required):

YES

No hardcap/pace program alerts are sent until this YES is received.

4

Opt-in confirmation (enrollment complete)

Budget Bot: You’re confirmed for Budget Bot SMS. We’ll text only for hardcap/pace budget alerts you requested. Msg frequency varies (typically <10/mo). Msg & data rates may apply. Reply STOP to cancel, HELP for help. Privacy: https://zaz-astra.tail5d74e1.ts.net/budget-bot/privacy.html Terms: https://zaz-astra.tail5d74e1.ts.net/budget-bot/terms.html

Budget Bot: Hardcap warning — spend is near your $[LIMIT] monthly limit ([PERCENT]% used). Reply STOP to cancel, HELP for help. Msg & data rates may apply.
